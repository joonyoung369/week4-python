# 힘 단위 변환기

Python Tkinter로 만든 데스크톱 프로그램입니다. 입력한 힘의 값을 선택한 단위에서 다른 단위로 변환하고, 결과를 소수점 둘째 자리까지 표시합니다.

## 실행

PowerShell에서 프로그램 파일이 있는 폴더로 이동한 뒤 실행합니다.

```powershell
python ".\힘 단위 변환기0923.py"
```

## 필요한 환경

- Python 3.6 이상
- Tkinter가 포함되고 GUI 창을 표시할 수 있는 Python 환경

Tkinter는 Python 표준 라이브러리이지만, Python 설치에 따라 별도 구성 요소가 필요할 수 있습니다.

## 지원 단위

`N`, `kN`, `MN`, `kgf`, `lbf`, `ozf`, `dyn`

## 입력 예시

초기 선택값은 입력 단위 `kN`, 출력 단위 `N`입니다. 입력값에 `1`을 넣고 **변환**을 누르면 `1000.00 N`이 표시됩니다.

입력값 앞뒤의 공백은 제거되며, 쉼표는 입력값에서 제거됩니다. 예를 들어 `1,000`은 `1000`으로 처리됩니다. 유한한 음수도 숫자로 처리됩니다.

## 오류 입력 예시

다음 값은 정상적인 유한 숫자로 변환되지 않아 오류 안내가 표시됩니다.

| 입력값 | 이유 |
| --- | --- |
| 빈 값 | 숫자로 변환할 수 없음 |
| `abc` | 숫자로 변환할 수 없음 |
| `nan` 또는 `inf` | 유한한 숫자가 아님 |

오류가 발생하면 결과 영역에 `입력을 확인해 주세요.`가 표시되고, 숫자와 지원 단위를 입력하라는 안내가 나타납니다.
